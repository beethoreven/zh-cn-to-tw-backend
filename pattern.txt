# 繁化助手 Stage 2「套用範本修改」的預設範本
#
# 格式：一行一條規則，寫成「修改前 → 修改後」（中間的箭頭是「→」）。
# 井字號（#）開頭的行是註解，空行會略過。
#
# 不用寫進這裡的（Stage 2 會自動處理）：
# - 半形標點轉全形：, ! ? : ; ( ) 轉成 ，！？：；（）
#
# 半形空格一律保留、不會被刪（劇本裡常有英文），規則裡也不能有空白。
#
# 注意：規則越短越容易跨詞誤中（例如「這只」會改到「這只是…」），
# 加新規則前先想想它會不會出現在別的詞裡。
